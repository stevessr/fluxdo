# Fluxdo offline font and emoji pack

Optional universal Android APK, separate from the main Flutter app. No launcher entry, Internet permission, native libraries or background service. Install alongside Fluxdo and choose fonts in Appearance or post-body emoji styles as usual. The host validates the catalogue fonts by SHA-256 and the emoji fonts by pinned Git blob SHA-1 and size. It reads only fixed asset paths in the companion package, without loading plugin code. Standard artwork is used only for post bodies; server custom emoji remain unchanged.

The build collects the redistributable body/mono catalogue, Noto/Twemoji/OpenMoji color fonts, static Discourse artwork sets, Google Noto 3D artwork and animated Noto artwork converted to 128px WebP with preserved frame durations. Missing standard artwork falls back to the local static set or system glyph. MiSans is intentionally excluded from the public resource APK because standalone redistribution is restricted; it retains the existing download option. Fonts are copied on demand; no bulk extraction is required. If the pack isn't installed, the existing network behavior remains.

CI builds a signed universal APK on matching PRs and publishes it as a separate Nightly asset after a successful main build. See bundled licenses and attribution files; animated Noto artwork is CC BY 4.0, resized and converted from the pinned Discourse distribution. The pack is larger than Fluxdo's main APK; keeping it optional avoids increasing normal app downloads.
