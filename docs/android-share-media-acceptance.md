# Android 分享、快捷入口与媒体后台播放验收

对应 PR #144。CI 负责静态分析、Dart 测试、Android Kotlin 编译；
以下系统集成场景需要真实 Android 设备（建议 Android 10、13、15/16）核验。

## 1. 分享到新主题

1. 安装当前 PR 构建，分别在 **应用未启动**、**后台常驻**、**前台正在浏览帖子** 时测试。
2. 从浏览器分享网页链接；确认新主题标题/正文预填、发布前可编辑，退出时草稿不意外被覆盖。
3. 从相册分享 JPEG/PNG/WebP/HEIC 图片、相册多选图片；确认文件确实进入上传任务队列，上传完成生成站点短链，不包含手机本地文件路径。
4. 从文件管理器分享 PDF/ZIP，并分享 MP3、MP4 等媒体；确认音视频经过同应用内选取媒体一致的上传/压缩与 `.xz` 嵌入流程，普通文件仍作为附件插入。
5. 对同一编辑器在附件尚未排队及上传过程中尝试发布：应提示等待上传；上传失败仍阻止发布。
6. 在第一条分享的编辑器未退出前，从其他应用再次分享；后续分享应被缓冲，当前编辑器关闭后再打开下一条，内容不串帖。
7. 测试不可读取的 URI、超长文件和超过 10 个的多文件分享；应提示跳过数量，不静默打开空帖。
8. 从分享页面取消编辑，确认不泄漏 URI 临时访问授权。冷启动旧缓存文件应按 48 小时保留期清理。

纯文字分享可以通过 ADB 冒烟验证：

```sh
adb shell am start \
  -a android.intent.action.SEND \
  -t text/plain \
  --es android.intent.extra.SUBJECT 'Android Share Smoke Test' \
  --es android.intent.extra.TEXT 'https://linux.do/' \
  -n com.github.lingyan000.fluxdo/.MainActivity
```

## 2. 图标快捷入口

1. 长按经典图标、切换现代图标后分别长按，检查出现且仅出现 **新主题、新私信、搜索**。
2. 三个入口应直接打开对应编辑器或搜索页面；在冷启动和热启动下各测试一次。
3. 触发新私信时需可选择收件人，而不是直接向预设用户发消息。
4. 对未登录、账号切换、被系统回收再冷启动等情况检查导航与状态。

## 3. 音频后台播放

1. 在帖子内播放音频后滑动使该帖子被列表回收、进入其他页面、切到桌面并熄屏，音频应持续播放。
2. 测试通知栏、锁屏、耳机的暂停/继续、进度、倍速；同一时间只允许一个帖内音频播放。
3. 测试暂停后重新播放、播至结尾再点击播放、从音频 A 切换到 B、快速连点切换。
4. 关闭 **偏好设置 → 媒体播放 → 音频后台播放** 后再将应用退到后台，应暂停；回前台仍允许正常播放。
5. Android 检查媒体前台服务通知；iOS 检查锁屏播放器与后台音频，不要将其误认成后台通知轮询服务。

## 4. 视频画中画

1. 进入视频全屏并播放，切到桌面，确认触发 Android PiP，画面不是整个帖子列表。
2. 切回应用，确认全屏控制条恢复且播放位置延续；关闭 PiP 以及转屏时不泄漏播放器。
3. 暂停视频后切后台不应主动进入 PiP；关闭 **视频画中画** 设置后切后台亦不应进入。
4. 竖版、横版视频及 Android 8.0+ 设备分别核对有效宽高比与系统切换行为。

## 5. 当前平台边界

Android 分享目标、启动器快捷入口和 Android 视频 PiP 在本 PR 内实现。
iOS 在本 PR 里仅接入音频后台播放；iOS Share Extension、Home Screen Quick Actions 和 iOS PiP 需要独立原生适配与 Xcode 验收。
